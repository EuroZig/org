# Legal Documents for EuroZig

This repo now contains the bylaws, the membership fee regulations, and a template for letters and other documents.

**The German documents are lagally binding, but all communicaltion should be in English.**
When working on things, please try to keep the two versions in sync. In tagged versions, they **need to be in sync**.

All documents are authored in [Typst](https://typst.app/). There is a CI job that compiles the documents.
